# Право Семьи

Семейно-правовая платформа Республики Казахстан.

## Текущий статус

Проект переведён на базовую архитектуру **React + TypeScript + Vite**. Первоначальная статическая версия сохранена в `prototype/index.html`.

## Технологии

- React 19
- TypeScript
- Vite
- CSS (адаптивная светлая тема)

## Локальный запуск

Требуется установленный Node.js (рекомендуется актуальная LTS-версия).

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Структура

```text
pravo-semi/
```

## Направления развития

1. Разделить интерфейс на самостоятельные модули и страницы.
2. Подключить Supabase: базу данных, Auth и Row Level Security.
3. Реализовать защищённую административную панель и роли пользователей.
4. Создать правовые сценарии по семейному законодательству РК.
5. Добавить библиотеку проверенных шаблонов и конструктор DOCX/PDF.
6. Реализовать безопасную загрузку и формальную проверку документов.
7. Подготовить двуязычный контент на русском и казахском языках.

## Юридическая точность и безопасность

- Все правовые материалы должны проверяться по действующей редакции законодательства Республики Казахстан.
- Необходимо различать прямые последствия закона и вероятные исходы, зависящие от фактов, доказательств и решения суда.
- Нельзя обещать гарантированный результат судебного разбирательства.
- Не следует хранить пароли, ключи API и другие секреты в Git. Используйте локальный файл окружения и серверные секреты хостинга.
- Перед сбором персональных или семейных данных необходимо спроектировать минимизацию данных, безопасность и политику конфиденциальности.

## Важно

Текущая версия — стартовая техническая основа и демонстрационный интерфейс, а не готовая юридическая платформа. Подключение базы данных, авторизации, ИИ и проверенных юридических документов ещё предстоит выполнить.
