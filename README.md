# Право Семьи

Первая версия семейно-правовой платформы Республики Казахстан.

## Текущий статус

Интерфейс первой версии расширен: адаптивная главная страница, тематические направления, интерактивный опросник-сценарий, поиск и фильтрация библиотеки документов, база знаний с FAQ и предварительный макет административной панели.

**Важно:** это пока клиентский демонстрационный интерфейс. Правовые выводы, генерация документов, загрузка и проверка файлов, аккаунты, сохранение данных и защищённая админ-панель ещё не подключены.

## Технологии

- React 19
- TypeScript
- Vite 6
- CSS (адаптивная светлая тема)

## Локальный запуск

Требуется Node.js (рекомендуется актуальная LTS-версия).

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Реализовано в интерфейсе

1. Главная страница и навигация по разделам.
2. Переключение языка интерфейса (основные элементы и направления; полный перевод контента ещё требуется).
3. Карточки направлений семейного права.
4. Интерактивный опросник по пяти темам: брак, развод, имущество, алименты и права ребёнка.
5. Поиск и фильтрация библиотеки документов.
6. База знаний и раскрывающиеся ответы на частые вопросы.
7. Макет панели администратора с перечнем будущих модулей.
8. Адаптивная компоновка для мобильных и настольных экранов.

## Правовая модель документов

В репозитории добавлен внутренний реестр требований к юридическим документам (`src/data/documentRequirements.ts`) и описание процесса юридической проверки (`docs/legal-document-engine.md`). Первые карты охватывают иск о расторжении брака, брачный договор, соглашение о разделе общего имущества и соглашение об уплате алиментов. В интерфейсе карточки этих документов открывают подробную правовую карту: источники, содержание, форму, приложения, процессуальные условия и ограничения. Все карты имеют статус черновика и не публикуются как готовые юридические формы до дополнительной проверки.

## Автоматическая проверка

GitHub Actions запускает TypeScript-проверку и production-сборку при push в `main`, pull request и вручную (`.github/workflows/build.yml`).

8. Подготовить политику конфиденциальности, правила хранения и удаления данных.

## Юридическая точность и безопасность

- Правовые материалы должны проверяться по действующей редакции нормативных правовых актов Республики Казахстан, прежде всего по официальным источникам.
- Для каждого правового материала нужно фиксировать дату проверки и редакцию акта.
- Необходимо различать прямые последствия закона и вероятные исходы, зависящие от обстоятельств, доказательств и оценки суда.
- Нельзя обещать гарантированный результат судебного разбирательства.
- Не следует собирать или хранить чувствительные семейные данные без обоснованной необходимости, прозрачных правил и технических мер защиты.
- Секреты API, пароли и service-role ключи нельзя помещать в Git.

## Ограничения текущего прототипа

Опросник работает локально в браузере и не отправляет ответы на сервер. Документы показаны как каталог будущих материалов; сами юридические шаблоны не опубликованы. Панель администратора является макетом и не предоставляет административных полномочий или серверной защиты.
